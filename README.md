# js-fundamentos

Ejercicios de JavaScript escritos y verificados desde cero, para volver a afianzar los conceptos base antes de avanzar a temas más pesados (DOM, React, backend).

## Estructura

- `01-funcional/` — `map`, `filter`, `reduce`, `find`, `sort`
- `02-funciones/` — closures, callbacks, currying, rest/spread
- `03-async/` — callback → Promise → `async/await`
- `04-apis/` — `fetch`, manejo de errores, `response.ok`
- `proyectos/` — ejercicios integradores que combinan varios temas
